# 多设备巡检输出模板

多设备巡检最终答案必须是摘要型报告，避免逐设备展开检查项导致上下文过长。禁止展示工具调用、脚本名、命令、退出码、stdout/stderr、`## 巡检过程`、`## 原始报告`、逐设备详情块和跨设备对比块。

```markdown
## 巡检结论
- 目标：全部 AD 设备
- 场景：标准巡检
- 设备数量：2 台
- 异常设备：2 台
- 总体风险：🔴 高

## 设备概览
| 设备 | IP | 状态 | 综合评分 | 异常项 |
| --- | --- | --- | ---: | ---: |
| AD1 | 192.168.8.30 | ❌ 异常 | 🔴 59/100 | 10 |
| AD2 | 192.168.8.31 | ❌ 异常 | 🔴 65/100 | 11 |

## 全局共性问题
| 问题 | 建议 |
| --- | --- |
| 设备安全状态检查 | 设备安全状态检查 未达到预期状态，建议结合设备配置页确认业务影响后处理 |
| SSL 安全策略检查 | SSL 策略存在不安全算法或协议，建议禁用旧版本 |
```

如果没有所有设备共同存在的异常项：

```markdown
## 全局共性问题

未发现所有设备共同存在的异常项。
```

## 结构要求

| Section | 触发条件 |
|---------|---------|
| `## 巡检结论` | 始终 |
| `## 设备概览` | 始终 |
| `## 全局共性问题` | 始终 |

## 禁止展示

| 类型 | 示例 |
|------|------|
| 技术过程标题 | `## 巡检过程`、`## 原始报告` |
| 逐设备详情 | `### AD1 详细报告`、`### 设备详情` |
| 对比扩展块 | `跨设备对比`、`高频异常`、`重点关注设备` |
| 工具调用说明 | `工具调用`、`命令执行` |
| 命令结果字段 | `退出码`、`stdout`、`stderr` |
| 内部脚本名 | `connect.py`、`check.py` |
| 内部检查项 ID | `DEVICE_SAFE_CHECK`、`CPU_CHECK` |
| 技能/策略说明 | `根据技能`、`技能规则`、`根据 ad-check-analysis` |
| 原始字段表达 | 英文字段加等号的设备内部状态表达 |

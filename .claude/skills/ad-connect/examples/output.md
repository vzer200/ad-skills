## 结构说明

| Section | 触发条件 | 格式 |
|---------|---------|------|
| 表格模式 | 多设备 + `--format table`(默认) | 3 列表格 `| 设备 | IP | 状态 |` + 汇总行 |
| 单行模式 | 单设备 + `--format table`(默认) | 单行 `图标 host — 描述` |
| JSON 单设备 | 单设备 + `--format json` | `{"host", "status", "error?"}` |
| JSON 多设备 | 多设备 + `--format json` | `{"results": {...}, "summary": {...}}` |

### 状态图标映射

| status 值 | 图标 | 含义 |
|-----------|------|------|
| `ok` | ✅ 正常 | TCP/TLS 可达 + Basic Auth 通过 |
| `connect_fail` | 🔌 连接失败 | 设备不可达、端口不通、超时 |
| `auth_fail` | 🔑 认证失败 | 用户名或密码错误 (401/403) |
| `api_error` | ⚠️ API 异常 | 连接+认证通过，但 API 调用异常 |
| `error` | ❌ 错误 | 其他未分类异常 |
